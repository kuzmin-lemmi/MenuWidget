# MenuWidget

Windows-виджет для подготовки школьных меню к загрузке на сайт.

Пользователь выбирает комплект **«Меню 1–5»** или **«Меню 6–10»**, перетаскивает пять Excel-файлов и получает пять копий с новыми датами и именами. По воскресеньям программа напоминает о подготовке меню в выбранное пользователем время.

## Статус

Начат этап 1: есть собираемый WPF-макет, календарное ядро, контракты сервисов и 15 синтетических технических проверок. [Результаты и скриншоты](docs/STAGE_1.md). Рабочий экспорт, системные напоминания, установка обновлений и установщик ещё не готовы; пользовательский релиз не опубликован.

## Сценарий пользователя

1. Скачать установщик из GitHub Releases, установить программу и открыть ярлык.
2. Выбрать «Меню 1–5» или «Меню 6–10».
3. Перетащить пять `.xlsx` в окно либо выбрать их кнопкой.
4. Проверить распределение по дням с понедельника по пятницу; при необходимости исправить порядок.
5. Выбрать целевую неделю. В воскресенье по умолчанию предложена следующая.
6. Нажать «Подготовить 5 файлов» и получить отдельную папку для загрузки на сайт.

Комплекты сохраняются локально: повторный импорт каждую неделю не обязателен. Загрузка на сайт выполняется человеком.

## Разработчикам

Windows + .NET SDK из `global.json`. Проверенная команда сборки и технических проверок:

```powershell
./scripts/Build.ps1
```

Запускаемый интерфейсный макет и отрисовка семи состояний описаны в отчёте этапа 1. Это прототип; кнопки не объявляют несуществующий экспорт, расписание или установку выполненными.

## Границы первого релиза

Русский интерфейс, Windows, `.xlsx`, два комплекта по пять меню, календарный цикл, настольный виджет со значком в трее, drag-and-drop, выбор недели, локальные настройки, воскресные напоминания и установщик. Excel, Python и ручной запуск команд пользователю не нужны.

В первый релиз входит кнопка **«Проверить обновления»**: найти новую стабильную версию в GitHub Releases, показать изменения, скачать и установить её по нажатию пользователя, сохранив настройки и шаблоны.

Не входят: загрузка меню на сайт, облачная синхронизация, учётные записи, редактирование блюд, `.xls`/Word/PDF, мобильные версии и фоновая установка обновлений без действия пользователя.
