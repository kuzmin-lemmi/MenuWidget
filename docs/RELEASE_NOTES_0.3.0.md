# MenuWidget 0.3.0 — виджет на рабочем столе

Для Windows 11 x64. Установщик включает .NET: Excel, Python, SDK и дополнительные программы не требуются. Если установлена 0.2.2, новая версия ставится поверх неё; шаблоны, настройки и подготовленные меню сохраняются.

## Что нового

![Виджет](design/widget.png)

- **Виджет на рабочем столе.** Небольшая карточка в правом верхнем углу экрана показывает, какая сейчас неделя цикла — «Неделя 1» (меню 1–5) или «Неделя 2» (меню 6–10), — и какое меню сегодня, например «Сегодня № 9». Ниже — пять дней недели с датами, текущий день выделен. В субботу и воскресенье виджет показывает следующую неделю.
- **Щелчок по виджету открывает готовые меню.** Открывается папка с последними подготовленными файлами этой недели. Если меню ещё не подготовлены, открывается программа.
- Виджет можно перетащить мышью — место запоминается. ⚙ открывает программу, ✕ скрывает виджет; вернуть его можно через значок у часов → «Показать виджет».

## Исправления

- Окно «Проверьте пять меню» больше не закрывает программу, если в выбранной ячейке нет даты, адрес ячейки набран не до конца или файл повреждён. Ошибка показывается рядом с файлом.
- Повреждённый файл настроек больше не мешает запуску: программа сохраняет его копию, запускается с настройками по умолчанию и сообщает об этом. Шаблоны меню и готовые файлы при этом не затрагиваются.

## Проверки и ограничения

Проходят 48 синтетических проверок, включая номер недели и дня меню, поиск готовой папки недели и восстановление повреждённых настроек. Виджет проверен владельцем на рабочем столе.

Установщик не подписан: Windows может предупредить о неизвестном издателе. Виджет пока только в светлой теме. Реальные меню и личные настройки в выпуск не включены.
