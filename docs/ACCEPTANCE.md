# Приёмка и тестирование

## Календарь

- Опорный понедельник 12.10.2026 → меню 1–5; 19.10.2026 → 6–10; 26.10.2026 → 1–5.
- 05.10.2026 → 6–10: недели до опорной даты работают корректно.
- Воскресенье 18.10.2026 предлагает 19–23.10.2026. В субботу 17.10 — то же.
- Будний день предлагает текущую рабочую неделю; пользователь может выбрать другую.
- Переход месяца, года и високосный февраль не нарушают пять последовательных дат.
- Праздники не сдвигают цикл. Ручной выбор комплекта не меняет опорную дату.
- Без настройки цикла нет выдуманного номера сегодняшнего меню.

## Файлы

- Пять синтетических входов с датами 05–09.10 → результаты 19–23.10.2026 и соответствующие имена.
- Внутри дата хранится корректным Excel-значением и отображается как `19.10.2026`, не ISO-строкой и не числом serial.
- Исходные файлы имеют прежние контрольные суммы после импорта и экспорта.
- Открыть результат в поддерживаемом просмотрщике таблиц: нет предупреждения о восстановлении, оформление и печать сохранены. Где возможно, проверить Excel и LibreOffice.
- Сравнить все части OOXML: изменения ограничены выбранными датами и необходимыми локальными стилями. Проверить сохранность формул/кэша, листов, скрытых областей, объединений, размеров, рисунков и настроек печати.
- Проверить другой лист/ячейку, общие стили, системы дат 1900/1904.
- Пять файлов с произвольными именами: ручное распределение предсказуемо и сохраняется.
- Неполный комплект, дубли, служебный файл, неподдерживаемый формат, повреждённый ZIP и недоступная ячейка дают понятную ошибку.
- Формула вместо даты не перезаписывается молча.
- Открытый исходник: безопасно прочитать стабильную копию либо сообщить причину; частичный успех не считать успехом.
- Нет прав, файл занят, недостаточно места: старые шаблоны и готовые комплекты сохраняются, новый неполный комплект не публикуется.
- Повторная подготовка не перезаписывает ранее созданный каталог.

## UI

- Человек без инструкций командной строки проходит путь: выбор комплекта → пять файлов → дни → неделя → экспорт → папка.
- Drag-and-drop и диалог файлов дают одинаковый результат.
- Неполный комплект виден, экспорт недоступен; понятно, чего не хватает.
- Переключение комплектов не смешивает файлы.
- Настройки и шаблоны сохраняются после перезапуска.
- Окно читаемо при 100%, 125%, 150%, 200%; тексты и пять строк не обрезаются.
- Ключевые действия доступны клавиатурой; ошибки не обозначаются только цветом.
- После отключения второго монитора окно остаётся доступным.
- Закрытие скрывает в трей, «Выйти» завершает виджет; повторный запуск не создаёт дубликаты окон.

## Напоминания — на установленной версии Windows

- Включить напоминание на тестовое время: одно уведомление с правильной будущей неделей.
- Повторить с открытым UI, скрытым UI и после явного выхода из приложения.
- Изменить время: старое расписание не срабатывает.
- Выключить компьютер до события и войти позже: одно последнее пропущенное напоминание.
- Перезапуск и повторный вход не создают дубли.
- Действие «Открыть» активирует нужное окно; «Напомнить позже» переживает закрытие UI.
- Отключение функции удаляет основное и отложенное напоминания.
- Смена часового пояса, переход часов и ручная смена времени не порождают очередь уведомлений.
- При запрете уведомлений Windows программа сообщает, где проверить настройку, и не утверждает, что пользователь увидел уведомление.

## Установка, обновление и релиз

- Чистая заявленная Windows, стандартный пользователь: установка, ярлык, drag-and-drop, экспорт и уведомление без Excel/Python/SDK.
- Обновление тестовой версии сохраняет комплекты, цикл, расписание и каталог результатов.
- Удаление убирает ярлыки, задания и автозапуск; готовые файлы пользователя остаются.
- Установщик из GitHub действительно скачивается и запускается, контрольная сумма совпадает.
- Реальные меню и личные данные отсутствуют в истории Git и релизах.
- В release notes честно указаны поддерживаемые ОС, архитектура, подпись и непроверенные ограничения.
