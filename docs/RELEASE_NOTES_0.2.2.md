# MenuWidget 0.2.2 — первый тестовый выпуск

Для Windows 11 x64. Установщик включает .NET: Excel, Python, SDK и дополнительные программы не требуются.

## Начало работы

1. Скачайте `MenuWidget-Setup-x64.msi` и откройте его двойным щелчком.
2. Откройте ярлык MenuWidget на рабочем столе.
3. Выберите комплект «Меню 1–5» или «Меню 6–10» и добавьте пять файлов `.xlsx`.
4. Проверьте порядок понедельник–пятница, лист и ячейку даты.
5. В настройках задайте понедельник первой недели цикла. При желании включите воскресное напоминание и автозапуск.
6. Выберите нужную неделю и нажмите «Подготовить 5 файлов». Полученную папку загрузите на сайт самостоятельно.

Крестик скрывает окно у часов. Двойной щелчок по значку возвращает окно; команда «Выйти» находится в его меню. Напоминания используют Планировщик Windows и работают после выхода из программы. Удалить приложение можно через «Параметры → Приложения → Установленные приложения». Шаблоны, настройки и подготовленные меню сохраняются после удаления.

## В выпуске

- Импорт двух комплектов, подтверждение порядка и экспорт пяти копий с новыми датами и именами.
- Трей, защита от второй копии, положение окна, автозапуск.
- Воскресное напоминание, перенос на 30 минут и обработка пропущенного срока.
- Кнопка проверки стабильных обновлений GitHub, описание изменений, проверка размера и SHA-256, внешний помощник установки.
- Исправлен первый запуск без существующих заданий Планировщика; очистка при удалении привязана к владельцу установки.

## Проверки и ограничения

Проходят 44 синтетические проверки. На пяти настоящих меню проверены новые даты 19–23.10.2026, имена файлов, сохранность исходников и содержимого вне даты. Проверены установка, обновление через внешний помощник, сохранение меню, регистрация задач, удаление и повторная установка на Windows 11 x64, сборка 26200.

Это тестовый выпуск. Установщик не подписан: Windows может предупредить о неизвестном издателе. Чистая Windows без средств разработки и учётная запись без административных прав отдельно не проверены. Реальный показ уведомлений, ограничения «Не беспокоить», вход в Windows и разные мониторы требуют обратной связи пользователей. Переход именно через экран обновлений между двумя публичными стабильными выпусками ещё не проверен; установочная часть проверена локальными MSI.

Кнопка «Проверить обновления» использует стабильный канал. Этот тестовый выпуск помечен prerelease и не предлагается как стабильное обновление. Пока стабильных выпусков нет, программа сообщает об их отсутствии.

Реальные меню и личные настройки в выпуск не включены. Поддерживается только `.xlsx`; загрузка на сайт выполняется человеком.
