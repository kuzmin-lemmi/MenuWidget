# План разработки

Все пункты ниже изначально не выполнены. Документация не является реализацией. Порядок отражает зависимости; сроки здесь не оценены.

## Этап 1. Макет и технические проверки

- [ ] Нарисовать компактный виджет, настройки и экран первого запуска.
- [ ] Показать пустые, частично загруженные, готовые и ошибочные состояния.
- [ ] Уточнить и закрепить целевые Windows, SDK и архитектуры процессора.
- [ ] Проверить точечное изменение даты с полным сохранением остальных частей XLSX на синтетических файлах.
- [ ] Проверить регистрацию и показ уведомления из установленного приложения при закрытом UI.
- [ ] Проверить обновление установленной версии через скачанный установщик, безопасный отказ/откат и сохранность пользовательских данных.
- [ ] Выбрать упаковку, учитывая уведомления и установку обычным пользователем.
- [ ] Зафиксировать контракты модулей и команды сборки/тестирования.

Выход: согласованный макет и воспроизводимые доказательства двух рисков — сохранности XLSX и системного напоминания.

## Этап 2. Ядро и файлы

- [ ] Реализовать календарный цикл и предпросмотр пяти дней, независимые от UI.
- [ ] Импортировать и хранить два комплекта, валидировать каждый файл.
- [ ] Поддержать выбор листа/ячейки и системы дат Excel.
- [ ] Точечно менять дату и формат отображения.
- [ ] Реализовать атомарный экспорт в новую папку без перезаписи исходников.
- [ ] Покрыть содержательные сценарии тестами из ACCEPTANCE.

Выход: библиотека, которая из выбранного комплекта и понедельника создаёт пять проверенных файлов.

## Этап 3. Пользовательский интерфейс

- [ ] Первый запуск: комплекты, опорная дата цикла, время напоминания по желанию.
- [ ] Drag-and-drop и кнопка выбора файлов.
- [ ] Явный выбор комплекта и исправление распределения по дням.
- [ ] Предпросмотр пяти результатов, кнопка подготовки, открытие папки.
- [ ] Текущий день/меню, выходные, выбор целевой недели.
- [ ] Трей, скрытие/открытие, выход, опциональный автозапуск и «поверх окон».
- [ ] Сохранение настроек, позиции и выбранного каталога.
- [ ] Проверка масштабирования, клавиатуры и понятности ошибок.

Выход: полноценный пользовательский путь без командной строки.

## Этап 4. Напоминания

- [ ] Настройка воскресного времени, включение, отключение и тест уведомления.
- [ ] Регистрация, обновление и удаление системного расписания.
- [ ] Показ при закрытом окне и после явного выхода из приложения.
- [ ] Одно пропущенное напоминание после входа в Windows.
- [ ] «Открыть» и «Напомнить позже» с сохранением отложенного события.
- [ ] Защита от дублей, обработка смены времени/часового пояса.
- [ ] Уважение системного запрета уведомлений и диагностика.

Выход: проверенное расписание на установленной версии, а не только в отладчике.

## Этап 5. Установка и v0.1.0

- [ ] Self-contained сборка, установщик, ярлык, удаление.
- [ ] Чистая Windows без Excel, Python, SDK и заранее установленного runtime.
- [ ] Проверка обновления с сохранением пользовательских данных.
- [ ] Кнопка «Проверить обновления», состояния сети/API и сравнение стабильных версий.
- [ ] Описание изменений, «Установить»/«Позже», скачивание с прогрессом и отменой.
- [ ] Проверка манифеста, совместимости и SHA-256 до запуска установщика.
- [ ] Обновление из приложения с завершением активных операций, восстановлением при ошибке и повторным запуском.
- [ ] Манифест обновления в каждом релизе; проверка обновления между двумя реально собранными версиями.
- [ ] Проверка очистки заданий/автозапуска при удалении.
- [ ] Короткая инструкция, скриншоты, синтетические примеры и список ограничений.
- [ ] CI для сборки/тестов и контролируемая публикация prerelease v0.1.0.
- [ ] Проверка скачанного установщика и ссылки на релиз.

Выход: тестовый релиз для небольшой группы пользователей.

## Возможное разделение задач между агентами

После этапа 1 координатор может поручить независимые направления:

| Направление | Зона | Зависимости |
| --- | --- | --- |
| Календарь и XLSX | Core, Xlsx, синтетические тесты | Согласованные контракты |
| Интерфейс | WPF UI, сценарии и доступность | Контракты Application, макет |
| Напоминания | Расписание и активация | Выбранная упаковка, контракт UI |
| Сборка и приёмка | CI, установщик, ручные сценарии | Интегрированное приложение |

Интеграцию, сохранность пользовательского пути и достоверность отчёта проверяет координатор. Этот раздел описывает план будущей работы и не запускает агентов автоматически.
