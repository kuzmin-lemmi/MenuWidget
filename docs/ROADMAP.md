# План разработки

Порядок отражает зависимости; сроки здесь не оценены. Внешний вид согласован пользователем. [Результаты этапа 1](STAGE_1.md), [рабочая версия импорта/экспорта](STAGE_2.md). Уведомления по-прежнему требуют ручной проверки; их успешная доставка не заявляется. Пользователь попросил прекратить длительные прогоны и передать интерфейсную приёмку ему.

## Этап 1. Макет и технические проверки

- [x] Нарисовать компактный виджет, настройки и экран первого запуска; внешний вид согласован пользователем.
- [x] Показать пустые, частично загруженные, готовые и ошибочные состояния.
- [x] Закрепить Windows 11 x64 и SDK .NET 10 в global.json; проверка на чистой машине остаётся в релизной приёмке.
- [x] Проверить точечное изменение даты с полным сохранением остальных частей XLSX на синтетических файлах.
- [ ] Проверить регистрацию и показ уведомления из установленного приложения при закрытом UI.
- [x] Проверить локальный изолированный MSI-стенд: скачивание установщика, обновление, намеренный сбой с откатом, блокировка downgrade, сохранность искусственных настроек и запуск восстановленного приложения. Установка из пользовательского интерфейса обновлений — этап 5.
- [ ] Выбрать упаковку, учитывая уведомления и установку обычным пользователем.
- [x] Зафиксировать контракты модулей и команды сборки/тестирования.

Выход: согласованный макет и воспроизводимые доказательства двух рисков — сохранности XLSX и системного напоминания.

## Возможное разделение задач между агентами

После этапа 1 координатор может поручить независимые направления:

| Направление | Зона | Зависимости |
| --- | --- | --- |
| Календарь и XLSX | Core, Xlsx, синтетические тесты | Согласованные контракты |
| Интерфейс | WPF UI, сценарии и доступность | Контракты Application, макет |
| Напоминания | Расписание и активация | Выбранная упаковка, контракт UI |
| Сборка и приёмка | CI, установщик, ручные сценарии | Интегрированное приложение |

Интеграцию, сохранность пользовательского пути и достоверность отчёта проверяет координатор. Этот раздел описывает план будущей работы и не запускает агентов автоматически.
