# MenuWidget 0.3.3 — виджет появляется при входе в Windows

Для Windows 11 x64. Ставится поверх 0.2.2–0.3.2; шаблоны, настройки и подготовленные меню сохраняются.

## Исправлено

- **Виджет запускается вместе с компьютером.** Раньше после входа в Windows программа появлялась только у часов, а виджет приходилось открывать вручную. Если виджет один раз скрыли крестиком, он оставался скрытым при каждом следующем входе. Теперь виджет появляется при каждом запуске программы, в том числе при автозапуске.
- Крестик на виджете скрывает его только до следующего запуска. Вернуть сразу: значок у часов → «Показать виджет», ярлык MenuWidget или кнопка на вкладке «Виджет» в настройках.
- Запуск только ради воскресного напоминания (его делает Планировщик Windows) по-прежнему виджет не показывает.

## Проверки и ограничения

Проходят 50 синтетических проверок. Вход в Windows после перезагрузки на живом компьютере не проверялся — напишите, если виджет не появился.

Установщик не подписан: Windows может предупредить о неизвестном издателе.
